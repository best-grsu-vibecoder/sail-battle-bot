# Голландский штурвал 2.0 — Морской бой на JavaScript

Самостоятельная веб-версия игры для двух человек. Node.js обслуживает интерфейс и HTTP API; браузеры получают состояние раз в секунду. Внешние библиотеки и Telegram-токен не нужны. Исходный Python-бот сохранён отдельно в родительской папке.

## Запуск

Установите Node.js 22 или новее. В терминале из этой папки:

```powershell
cd C:\Users\alexander\Desktop\sail-battle-bot\web
npm start
```

Откройте http://localhost:3000. Создайте комнату и отправьте другу ссылку. Для проверки на одном компьютере используйте второй браузер или приватное окно: один профиль браузера хранит одну игровую сессию. Обновление страницы восстанавливает сессию.

## Игра по сети

В одной Wi-Fi сети друг открывает `http://IP-ВАШЕГО-КОМПЬЮТЕРА:3000`. Узнать локальный IPv4 можно командой `ipconfig`. Разрешите входящие TCP-соединения на порт 3000 в брандмауэре для частной сети. Ссылку на комнату копируйте со страницы, открытой по этому IP: localhost у друга указывает на его компьютер.

Для интернета скопируйте папку web на VPS/хостинг с поддержкой постоянно работающего Node.js. Команда запуска — `npm start`, порт берётся из переменной окружения `PORT` (по умолчанию 3000), адрес — `HOST` (по умолчанию 0.0.0.0). Настройте домен и HTTPS через reverse proxy, например Caddy:

```caddyfile
game.example.com {
    reverse_proxy 127.0.0.1:3000
}
```

Запускайте Node-процесс через менеджер служб вашего сервера, чтобы он восстанавливался после перезагрузки. Оба игрока должны заходить на один адрес сервера. Это приложение требует серверного процесса: загрузки только public на статический хостинг недостаточно.

## Возможности и ограничения

- Комнаты на двоих по коду/ссылке, ручная и случайная расстановка, поворот, подтверждение готовности.
- Сервер проверяет размещение, очередность ходов и повторные выстрелы; скрывает корабли противника. Попадание сохраняет ход, вокруг потопленного корабля отмечаются промахи.
- Адаптивный интерфейс, сдача, итог игры, восстановление подключения после временного обрыва сети.
- Комнаты хранятся в памяти одного процесса. Перезапуск сервера сбрасывает партии. Срок без игровых действий — 24 часа; несколько серверных процессов без общей базы не поддерживаются.
- Токен сессии хранится в localStorage. Код приглашения даёт доступ второму игроку; не публикуйте его до входа друга. Для публичного сервиса с большим трафиком потребуются общая база, мониторинг и защита от массового создания комнат.

## Проверка

```powershell
npm test
```

Тесты проверяют правила расстановки, бой до победы, скрытие флота, доступ по токену и работу двух клиентов через HTTP.
